## 1. The spotting session
In film post-production, a spotting session is a viewing with the director, composer, editor and sound
team to decide where music (and separately, effects) goes; the result is spotting notes listing cues by
scene with start/end times. For AI production run the same pass on the shot list or assembly: scene by
scene, moment by moment, decide music / no music / source, and why.

## 2. Functions of a cue
Emotion (deepen what the image shows), tension (anticipation, dread), pace (drive action), transition
(bridge scenes, time passing), irony (counterpoint to the image), character (theme for a person), place
and era (source music, instruments of a culture), humor (punctuation of a gag). One main function per cue.

## 3. Themes and leitmotifs
A theme is a short recognizable musical idea tied to a character, place or idea. Describe it so it can be
rendered: contour ("rises a fifth then falls stepwise"), rhythm feel, mode (major/minor/modal), instrument
that carries it. Transform it with the story: fragmented, slower, reharmonized, moved to another
instrument, in a different mode. Short films: one main theme, maybe a counter-theme.

## 4. Hit points and sync
Hit points are moments where the music must line up with picture: a door slam, a cut, a reveal, a look.
List them with time (or shot ID + offset). Music can hit an event exactly (accent), anticipate it, or land
just after it (reaction). Generated music rarely hits points by itself; plan to edit the music at phrase
boundaries or re-time picture slightly.

## 5. Entrances, exits, endings
- Enter under something (a sound, a cut, the end of a line) so the start is not noticed — or hard-start for
  impact.
- Exit on a motivated moment: a cut to silence, a fade under dialogue, a button ending (a short final hit).
- Avoid starting a cue in the middle of a key line.

## 6. Score, source and silence
- **Score:** non-diegetic, only the audience hears it.
- **Source:** diegetic, comes from the story world (a radio, a street musician); must match the scene's
  space (filtered, reverberant) — coordinate with the sound-designer.
- **Silence:** often the strongest choice before a scare, at a revelation, or after a loss.

## 7. Cue sheet fields
| Field | Example |
|---|---|
| ID | M02 |
| Start / end | SC02-SH010 +0.0 s → SC02-SH080 end (re-time after assembly) |
| Function | tension → pace (chase) |
| Description | low pulsing synth ostinato, taiko-like hits enter at the jump |
| Tempo / key / meter | 128 BPM, D minor, 4/4 |
| Instrumentation | analog synth bass, processed percussion, high string harmonics |
| Dynamics | starts pp, builds to ff at the jump, drops to silence on landing |
| Hit points | SC02-SH060 +1.2 s (jump), SC02-SH070 +0.4 s (landing → cut out) |
| In / out | under the door slam / hard cut to silence |
| Leaves room for | Maya's line at SH050 |
