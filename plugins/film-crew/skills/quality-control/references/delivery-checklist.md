# Delivery Checklist

Complete for the final QC stage. Items that depend on a platform's current rules are marked "confirm":
verify them against the platform's published delivery specification at delivery time.

## Picture
- [ ] Runtime matches the locked edit (measured)
- [ ] Resolution, aspect ratio and frame rate per delivery spec (measured with inspect_media.py)
- [ ] Vertical/square versions reframed, not squeezed, if required
- [ ] No unintended watermarks or tool overlays
- [ ] Titles, credits, subtitles: spelling, timing, safe areas

## Sound
- [ ] Integrated loudness and true peak within the target (measured) — confirm platform spec
- [ ] Dialogue intelligible throughout
- [ ] Stems delivered if required: dialogue, music, effects, M&E

## Files and records
- [ ] Master file plus required versions and codecs — confirm platform spec
- [ ] Asset registry updated with the final approved file for every slot
- [ ] Production log: all approvals recorded; open assumptions resolved or accepted by the user
- [ ] Rights log: every music track, sound library item, font, reference image with its license/source
- [ ] Tool log: which AI tools generated which assets (needed for disclosure and terms of use)

## Disclosure and rights (flag for the user; not legal advice)
- [ ] Platform or festival rules on AI-generated content disclosure — confirm current rules
- [ ] No real people's likeness or voices without documented consent
- [ ] No trademarks or copyrighted characters/music without rights
- [ ] Tool terms of use permit the intended (e.g. commercial) use — confirm per tool and plan
