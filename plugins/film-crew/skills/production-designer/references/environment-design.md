## 1. Story function first
Ask what the place does to the character: does it trap, shelter, expose, tempt, test? Design follows:
- **Trap:** low ceilings, narrow exits, hard surfaces, few windows.
- **Refuge:** warm practical light, soft materials, objects of care, one window to the world.
- **Exposure:** open space, high vantage, nothing to hide behind.
- **Threshold:** doors, stairs, bridges, a strong boundary line the character must cross.
Condition tells history: scuffs at hand height, sun-faded patches, repairs, dust where no one goes.

## 2. Floor plan format
Text plans are enough for blocking. Use a fixed grid, mark walls, doors (D), windows (W), landmarks (L1...),
furniture, and a north arrow or a named reference wall. Give rough dimensions.

```
              N ↑          (12 m x 8 m rooftop)
 +--------------------------------------+
 |  L1 water tower          L2 neon sign|  ← north parapet (street side, 5 floors down)
 |                                      |
 |     [AC units]        [skylight]     |
 |                                      |
 D1 roof door (stairwell)     W gap to next roof (1.5 m) → L3 next roof's antenna
 +--------------------------------------+
   south parapet: laundry lines between posts
```

Each landmark gets a one-line description and where it sits. Each exit says where it leads.

## 3. Landmarks and orientation
Audiences orient by big, distinct objects in backgrounds. Give every location 3-6 landmarks with different
shapes and colors spread around the space, so any camera direction catches at least one. Keep them fixed
across all shots; the script supervisor and QC check they stay put. When the script needs geography
(chases, escapes, "the door is behind them"), say which landmark is on which side.

## 4. Light sources
List every source the world provides, as the cinematographer will light from them:
| Source | Where | Color/temperature | Behavior |
|---|---|---|---|
| Neon sign "pink" | north parapet, faces street | magenta | buzzes, flickers every few seconds |
| Stairwell door | D1, open | cold fluorescent | spills when open |
| City glow | sky to the north | sodium orange haze | constant |
State which sources are on at which times and what can be switched or broken by the story.

## 5. Time of day and weather variants
For each variant the script uses: sky condition, sun/moon direction relative to the plan, wet/dry surfaces,
puddles and reflections, wind effects (laundry, plastic), visibility (fog, rain density). A location at dusk
and at night is one location record with two variants, not two locations.

## 6. Believability checklist
- [ ] Era and world rules respected (no anachronistic objects)
- [ ] Scale correct against the lineup heights (door 200 cm, railing 100 cm)
- [ ] Wear patterns where people touch and walk
- [ ] Signage language and style consistent with the world
- [ ] Every exit used in the script exists on the plan
- [ ] Every scripted action is physically possible in the space

## 7. AI-generation notes
- Generate the widest plate first; use it as the reference for other angles so architecture stays fixed.
- Plates without characters are easier to keep consistent; characters are added in keyframes.
- Readable signs and text: keep minimal, simple fonts, few words; flag for VFX if they must be legible.
- Repeating structures (windows, tiles, railings) may come out irregular; describe count and rhythm only
  if it matters ("three windows evenly spaced").
- Reflections and mirrors are high risk; avoid mirrors in key blocking unless needed.
